# R Data Analysis

A collection of practical R scripts and examples for data analysis workflows.

This repository contains commonly used R codes for data importing, preprocessing, exploratory data analysis, visualization, statistical analysis, and basic machine learning applications.

## Topics Covered

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Data visualization
* Statistical analysis
* Correlation analysis
* Machine learning models

## Libraries Used

* tidyverse
* ggplot2
* dplyr
* caret
* randomForest
* xgboost

## Purpose

This repository serves as a reference for practicing and applying R programming techniques in data analysis and data science projects.
